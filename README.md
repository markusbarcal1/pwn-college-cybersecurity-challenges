# Cybersecurity Challenges

Curated cybersecurity challenge solutions from 398+ completed exercises covering web exploitation, cryptography, and binary analysis.

## Focus Areas
- Web exploitation
- Cryptography
- Binary exploitation
- Python automation

## Tools Used
- Python
- pwntools
- Wireshark
- GDB

## Repository Structure
- `web-exploitation/` — selected scripts for web security challenges
- `cryptography/` — oracle and encoding-based attack scripts
- `binary-exploitation/` — automated exploit scripts for memory corruption challenges
- `utilities/` — small helper tooling used during challenge solving

## Notes
This repository is a curated subset intended to highlight representative technical work rather than every individual challenge completed.
